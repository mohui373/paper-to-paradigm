# 科普与传播主张核验路线

仅当用户要求核验博主、新闻、社交媒体、科普文章或其他二手传播中的研究主张时读取本文件。本路线不是通用事实核查器，也不推断传播者是否故意误导。

## 1. 建立核验对象

先收集并分开保存：

- 传播者的准确原话、标题、截图或链接；
- 对方实际引用的论文、DOI 或其他来源；
- 用户希望判断的具体命题；
- 传播时间、目标人群和上下文；
- 是否涉及健康、安全、法律或其他高风险决策。

若找不到引用论文，只能核验“来源不可追踪”，不能假装已经核验原文。若传播者引用的是综述、指南或新闻稿，先识别来源类型，再决定是否继续追到原始研究。

## 2. 把传播语言拆成可核查命题

重点识别：

| 传播表达 | 需要还原的研究问题 |
|---|---|
| “X 导致 Y” | 原研究是否能识别因果，还是只有横断相关或观察性关联？ |
| “一定、所有人、任何时候” | 样本、情境、剂量、时间和排除标准是否支持普遍化？ |
| “显著改善” | 统计显著、效应大小、置信区间和实际意义分别如何？ |
| “科学证明” | 是单篇探索性研究、重复研究、Meta-analysis 还是指南证据？ |
| “没有副作用/风险” | 研究是否测量风险，样本量和随访是否足以发现风险？ |
| “专家都同意” | 是 Delphi 赞同率、正式指南，还是非系统性专家意见？ |

## 3. 对齐论文证据

至少核对以下字段：

1. 研究类型与可支持的推断层级；
2. 样本来源、样本量、代表性与排除标准；
3. 自变量/暴露、因变量/结局和关键协变量的操作化；
4. 对照条件、时间范围、剂量和研究情境；
5. 原始结果、效应量、置信区间、不确定性和稳健性；
6. 作者原结论、作者明示限制与本 Skill 识别的边界；
7. 传播主张是否省略了条件、替换了指标或提升了因果层级。

## 4. 给出有限等级判断

使用以下五类之一，不强迫所有问题得出真/假二分：

- `一致`：主张的对象、方向、强度、因果层级和边界与论文基本相符。
- `部分一致`：核心方向有证据，但省略了重要条件或不确定性。
- `过度概括`：从特定样本、替代指标、相关关系或平均效应扩展为普遍/因果/绝对结论。
- `不受支持`：论文结果与主张不一致，或论文没有测量该命题。
- `目前无法判断`：原文、补充材料、关键统计或后续证据不足。

输出一张对照表：

| 传播主张 | 原论文实际结果 | 判断 | 关键差异 | 对日常理解的含义 |
|---|---|---|---|---|

## 5. 按研究类型调整

- 实验/RCT：检查随机化、对照、依从性、操纵、结局和因果边界。
- 横断问卷：强调相关不是因果，检查共同方法、反向关系和样本限制。
- 纵向研究：检查时间顺序、流失、间隔、时间变化协变量和效应层级。
- Meta-analysis：检查纳入研究、效应口径、异质性、预测区间、偏倚和证据质量。
- 系统综述/指南：检查搜索完整性、研究质量、证据确定性和推荐强度。
- Delphi/共识：专家赞同率不等于实验效应或高确定性证据。

## 6. 外部校准

无论论文新旧，均按 `anatomy-protocol.md` 的 C4 规则保留领域锚点：近三年论文提供 3–5 篇精简定位性来源，较旧论文默认约 5 篇以上进展、复制、修正或争议证据。主张影响较大、单篇研究被当成领域结论或用户明确问“现在是否仍成立”时，应优先检索系统综述、Meta-analysis、重复研究、正式指南和高相关反证。记录查询范围；未检索或无法检索时不得声称当前共识或研究空白。

## 7. 安全边界

- 不把论文核验写成个体化医学诊断、治疗或停药建议。
- 不因表述夸张就推断传播者的主观动机。
- 不用论文数量代替证据质量，不用期刊声誉代替方法审查。
- 不因标题、摘要或显著性与主张方向一致就跳过全文方法和限制。
