## 1. 先判型

依据摘要、Methods、结果生产方式和作者声明判断，不依据标题猜测。先给一个主要类型，必要时附一个次要类型及判断置信度。

| 类型 | 识别信号 | 其“数据”是什么 | 不能误当成什么 |
|---|---|---|---|
| 理论/概念论文 | 构建命题、模型、类型学或机制框架；未执行可重复检索 | 概念、理论命题和选择性文献论证 | 系统综述或已验证模型 |
| 叙述/整合综述 | 围绕问题整合文献，检索与筛选可能不完全可重复 | 被作者选择并组织的研究 | 穷尽性证据地图 |
| 系统综述 | 明确数据库、检索式、纳入排除、筛选和质量评价 | 纳入研究及其特征/结果 | 自动等于高质量证据 |
| 范围综述 | 主要绘制研究范围、概念、方法和空白 | 领域分布与研究特征 | 效果大小或干预优劣结论 |
| 元分析 | 将可比效应量统计合并 | 每个独立样本的效应及抽样误差 | 单一大样本实验或天然因果证据 |
| 元分析结构方程模型 | 汇总相关矩阵后估计路径模型 | 研究层相关矩阵和模型参数 | 个体层纵向机制证明 |
| 伞形综述 | 综合多个系统综述/meta-analysis | 综述层结果、质量和重叠 | 没有重复样本的全新证据库 |
| 文献计量/科学知识图谱 | 共引、共词、作者、期刊或国家网络 | 文献记录及网络关系 | 理论有效性、因果关系或效应量 |
| Delphi/专家共识 | 专家多轮判断、反馈并达到阈值 | 逐轮意见和赞同比例 | 实验效应量或证据确定性 |
| 指南/立场声明 | 将证据和价值判断转成建议 | 证据等级、推荐强度和利益相关者判断 | 单纯文献综述 |

混合论文按主要产出判型。例如“系统综述 + meta-analysis”以 meta-analysis 为主、系统综述为次；“证据综述 + Delphi”若最终产出是建议，则以共识/指南为主。

## 2. 所有非原始实证论文的共同主线

### 2.1 中心观点地图

先用一句话写作者的总论点，再拆成 3-7 个可核查子命题。每个子命题回答：

```text
作者主张什么
-> 直接引用哪些关键来源
-> 来源提供理论、实证、方法还是背景支持
-> 证据方向是否一致
-> 有无反证、空白或过度推广
```

优先做“命题-来源矩阵”，而不是按参考文献顺序摘要。

| 作者的关键命题 | 承担该命题的理论/文献 | 证据类型 | 支持程度 | 反证/边界 | 本文如何推进 |
|---|---|---|---|---|---|

### 2.2 引文功能与源头审计

将关键来源标为：

- `奠基理论`：提出核心机制或构念；
- `后续整合`：重构、扩展或连接多个理论；
- `直接实证`：实际检验目标关系；
- `相邻实证`：构念或场景相近，但不直接检验；
- `反证/边界`：结果不一致或限定适用范围；
- `方法来源`：支持测量、检索、编码或统计方法；
- `背景/权威来源`：说明问题重要，但不直接支持机制。

警惕 `citation laundering`：焦点论文引用一篇综述来支撑强命题，而综述所引原始研究并未直接检验该命题。关键路径至少回溯到一层原始或奠基来源；不能访问时标为“未能核实”。

### 2.3 证据强度不是文献数量

综合判断：设计质量、样本与场景多样性、测量一致性、因果识别、结果一致性、精确度、偏倚风险和可复核性。大量横断自陈研究不能因数量多就升级为因果机制。

明确区分：

```text
未研究/证据缺失
证据不足或不确定
平均效应接近零
不同条件下方向相反
有统计效应但实践意义很小
```

### 2.4 观点到讨论的闭环

```text
纳入或引用的证据
-> 作者形成的综合判断
-> 理论上新增的整合、机制或边界
-> 实践/政策建议
-> 证据允许推广到哪里
```

“提出一个框架”与“框架得到验证”必须分开。

## 3. 各文献类型的专用审查

### 3.1 理论、概念与叙述综述

**A 重点**

- 核心概念怎样定义，是否发生概念漂移；
- 作者如何从已有理论推出新框架、类型学或命题；
- 每条模型路径实际引用了谁，原来源是否真的支持；
- 是否公平呈现竞争解释和不一致证据。

**B 重点**

- 文献选择原则是否透明；
- 给出 3-6 个承担核心命题的代表性实证研究：样本、方法、核心结果、支持哪条命题；
- 区分原始实证、综述证据、案例说明和作者推理；
- 将概念模型转成可检验的变量、操纵、时间顺序或边界条件，但不要伪装成已完成实验。

**C 重点**

- 贡献属于新构念、新机制、理论整合、类型学、边界还是研究议程；
- 哪些命题已有实证，哪些只是待检验；
- 旧理论论文必须用约 5 篇代表性后续研究检查命题后来被支持、修正还是放弃。

### 3.2 系统综述与范围综述

**A 重点**

- Review question、PICO/PECO/SPIDER 或其他问题框架；
- 作者想解决的是效果、机制、范围、方法差异还是证据缺口；
- 最终综合观点如何超越“有多少篇研究”。

**B 重点**

| 审查项 | 应回答的问题 |
|---|---|
| 检索 | 数据库、检索式、日期、语言和灰色文献是否充分？ |
| 协议 | 是否预注册，偏离协议了吗？ |
| 筛选 | 纳入排除标准、双人筛选、PRISMA 数量是否可复核？ |
| 编码 | 研究特征、结局和结论如何编码？一致性如何？ |
| 质量 | 使用何种偏倚/质量工具，是否真正影响综合判断？ |
| 综合 | 叙述、主题、vote counting 或其他方法是否适合问题？ |
| 缺口 | “没有研究”来自检索边界还是领域真实空白？ |

范围综述主要评价覆盖、分类和证据地图，不强求效应量或确定性结论。系统综述若没有 meta-analysis，要解释不能合并的原因，不能用“显著研究数量”代替效应综合。

### 3.3 Meta-analysis

除系统综述项目外，必须解释：

| 维度 | 核心问题 |
|---|---|
| 效应构造 | 使用 `r/rho`、Cohen's `d`、Hedges' `g`、SMD、OR、RR 还是其他指标？方向如何编码？ |
| 独立性 | 同一研究多个效应如何处理：平均、选择、多层模型、RVE？ |
| 模型 | 固定效应还是随机效应？估计方法和权重是什么？ |
| 平均效应 | 大小、95% CI、实际意义；不要只写显著性 |
| 异质性 | `Q`、`tau²`、`I²` 和预测区间说明什么？高异质性时平均值代表性多大？ |
| 调节 | 事前理论还是事后探索？研究层调节能否推广到个体层？ |
| 偏倚 | funnel、Egger、选择模型、PET-PEESE、p-curve 等是否适合且结果一致？ |
| 稳健性 | 影响研究、leave-one-out、异常值、质量筛选、口径变更后是否稳定？ |
| 确定性 | 是否用 GRADE 或类似标准；结论强度是否与偏倚和异质性匹配？ |
| 开放性 | 逐效应数据、代码、变量字典和预注册是否可获取？ |

效应量表至少包含：结局/关系、`k`、总 N、效应口径、点估计、CI、异质性、结论和不可推出之处。必要时提示可以进一步给出 R 复核方案，但默认不让代码挤占阅读主体。

### 3.4 Meta-analytic SEM

额外检查：相关矩阵如何合并、缺失相关如何处理、第一阶段异质性、第二阶段模型拟合、替代模型、直接/间接效应，以及生态谬误风险。跨研究相关支持“变量共同变化”，不能单独证明个体内时间机制。

### 3.5 Umbrella review

检查综述之间的原始研究重叠、重复计算、综述质量、证据一致性和确定性分级。不能把多篇高度重叠的 meta-analysis 当作多次独立复制。

### 3.6 Bibliometric review

解释数据库、检索式、去重清洗、分析单位和算法参数；区分共引、文献耦合、共词和合作网络。聚类代表文献结构或话题关联，不直接证明理论机制、研究质量或实际效应。

### 3.7 Delphi、专家共识与指南

| 维度 | 核心问题 |
|---|---|
| 证据底座 | 系统检索还是专家供稿？质量与确定性如何？ |
| 专家组成 | 门槛、数量、地域、性别、学科、实践者/患者代表性如何？ |
| 初始陈述 | 谁起草，是否产生框架效应？ |
| 独立性 | 回应匿名、专家互盲和研究者盲法分别做到什么？ |
| 轮次与阈值 | 阈值是否预设、退出规则和失访如何处理？ |
| 分歧 | 少数意见、措辞变化和未达共识事项是否公开？ |
| 利益冲突 | 专家是否也是底层证据作者或存在专业立场？ |
| 推荐强度 | 是否区分专家赞同率、效果大小、证据确定性和推荐强度？ |

必须用一句显眼说明：`共识百分比 != 效应量 != 证据确定性 != 推荐强度`。

## 4. 容易遗漏的维度

除用户提出的“观点及其理论/文献支持”外，默认再检查以下维度：

1. **反证与争议是否被公平纳入**：作者有没有只选择支持自身框架的研究？
2. **概念与测量是否对齐**：相同术语是否实际使用不同量表、对象或时间尺度？
3. **证据层级与因果语言是否匹配**：横断相关、实验、纵向和质性证据不能等价。
4. **效应量是否有实践意义**：显著但很小、高异质或预测区间跨零时要降调解释。
5. **结论依赖哪些关键假设**：编码、研究独立性、模型、阈值或分类一改变，结论是否仍成立？
6. **可复核性与开放材料**：检索式、纳入表、编码表、逐效应数据、代码、协议和利益冲突。
7. **领域代表性**：文化、国家、行业、样本、语言和发表来源是否过窄。
8. **贡献究竟是什么**：分类整理、理论整合、机制、边界、方法改进、证据量化或实践指南，不笼统写“丰富了文献”。
9. **当前状态**：旧文献的核心命题后来被支持、修正、否定还是转向；没有检索不得宣称空白。
10. **可检验性**：理论框架能否转成明确变量、比较、时间顺序和可证伪预测。

## 5. 篇幅与检索控制

- 不把每篇综述写成方法学教科书。先报告最影响结论的 3-6 个判断，再给必要细节。
- 中心命题通常拆成 3-7 条；理论源头通常审计 3-8 个关键来源，不穷举参考文献表。
- 理论/叙述综述主动提供 3-6 个高相关实证入口；优先直接检验核心命题、方法质量高或提供反证的研究。
- 旧文献默认联网长检索约 5 篇代表性后续来源；新文献只有在判断创新性、争议或当前证据时扩展检索。
- A 讲作者提出什么，B 讲证据如何获得并是否支持，C 讲这一综合改变了什么及其边界，避免三部分重复。
