# 领域与研究设计适配

在跨领域、问卷、纵向、组织现场或个性化创新任务中读取本文件。不要为了证明 Skill “通用”而把所有研究强行写成实验程序。

## 1. 先决定能否重组

| 输入研究 | 本 Skill 的处理 |
|---|---|
| 实验、准实验、行为任务 | 完整 ABCDE：被试流程、平台/现场协议、材料、日志、分析与验证 |
| 横断问卷 | 将问卷平台视为运行平台；重建招募、同意、区组/题项逻辑、质控、数据字典和模型 |
| 纵向/多波问卷 | 在横断路线基础上增加波次、间隔、匿名链接、提醒、流失、时间变化变量和纵向模型 |
| 组织档案 + 个体问卷 | 明确组织/团队/个体层 ID、聚合规则、有效 N、跨层链接与权限边界 |
| 现场研究 | 把现场协议视为平台；还原角色、脚本、时间、匹配、支付、人工判断和日志 |
| 纯定性研究 | 只在用户要求重建访谈/编码协议时使用；否则由 `paper-anatomy` 解释证据 |
| 理论、概念、综述、Meta、Delphi | 默认转 `paper-anatomy`；除非用户明确要求复现检索、筛选、编码或共识流程 |

非实验路线仍要保留 ABCDE 的功能对应，但不得虚构屏幕、操纵或原作者程序。D4 使用研究团队实际采用的分析环境；未指定时给平台中立分析契约，不能塞入装饰性 R 代码。

横断、纵向、多层组织问卷同时读取 `survey-longitudinal-path.md`；目标平台不是 E-Prime 时按需读取 `platform-adapters.md`。

## 2. 领域侧重点

### 实验心理学

- 理论构念与任务过程是否对齐；
- 刺激、时序、练习、反馈、正确率/反应时及排除；
- 任务难度、疲劳、学习和速度—准确权衡。

### 社会心理学

- 社会存在、身份、共享历史和情境线索；
- 真人、延迟真人、实验者控制、预生成反馈或虚构玩家；
- 需求特征、怀疑探测、欺骗说明和事后告知。

### 组织行为与管理学

- 实验角色是否能代表真实组织关系、权力和资源依赖；
- 态度/意向是否被误写为实际工作行为；
- 个体、二元、团队和组织分析层级是否一致；
- 学生/众包样本结论迁移到组织员工时的边界；
- 组织档案、主管评价与员工问卷如何匿名匹配。

### 行为决策与行为经济学

- 激励是否相容，收益、损失、概率和信息是否透明；
- 角色、策略空间、互动顺序和对手真实性；
- 结果差异来自偏好、理解、风险态度还是支付结构。

### 健康与运动

- 对照条件、剂量、依从性、时间跨度和不良事件；
- 替代指标、行为指标和临床/实际意义的区别；
- 不把研究级复现方案写成个体医疗建议。

### 教育、传播与 HCI

- 实验任务与真实学习/平台使用情境的距离；
- 行为日志、停留、点击和短期测验能否代表长期结果；
- 设备、界面、可访问性和平台算法造成的差异。

## 3. 个性化创新门

先建立：

```text
原理论命题 → 原设计不变量 → 可调参数 → 用户新想法
→ 被试/受访者体验变化 → 新数据需求 → 新分析与验证
```

逐项判断：

1. 新变量是理论机制、边界条件、控制项还是结果替代？
2. 新情境改变了理论适用范围，还是只更换名词与材料？
3. 被试能否理解新增内容，会不会暴露假设或增加需求特征？
4. 新测量是否改变任务顺序、共同方法偏差或因果解释？
5. 新平台/群体是否需要重新 pilot、测量等值或操纵检验？
6. 当前文献是否已经存在同类扩展？未检索不得声称首次创新。

始终标记 `原文明确`、`外部证据支持`、`用户构想`、`复现建议` 和 `待验证`。
