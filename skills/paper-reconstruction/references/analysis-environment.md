# 分析环境选择与产物路由

只在任务需要统计复现、分析代码、模型接口或可分析数据时读取本文件。不要把分析软件问题变成首次使用问卷。

## 条件式提问

如果用户已经明确分析软件，直接采用，不重复询问。否则只问一次：

> 你或研究团队通常使用什么软件分析数据？可以选择 R、Python、SPSS、Mplus、MATLAB、Stata、SAS、JASP/Jamovi，或说明其他工具；如果暂时不确定，我会先提供平台中立的分析契约，不擅自默认 R。

如果用户未回答或不需要可执行代码，输出 `platform-neutral` 分析契约：明确数据单位、字段、排除、派生指标、模型、对比、表图和版本记录，再说明如何迁移到常见软件。

## 分析环境对应产物

| 环境 | 推荐产物 | 可复现性记录 |
|---|---|---|
| R | `.R`/Quarto/R Markdown、`renv.lock`、导入到导出管线 | R 与包版本、`sessionInfo()`、随机种子 |
| Python | `.py`/notebook、`pyproject.toml` 或锁文件、测试 | Python 与包版本、环境锁、随机种子、执行顺序 |
| SPSS | `.sps` 语法、变量/值标签、数据导入与 OMS 导出说明 | SPSS 版本、扩展模块、语法日志、输出对应表 |
| Mplus | `.inp`、数据文件契约、变量顺序与缺失编码、`.out` 核对表 | Mplus 版本、估计量、积分/迭代设置、随机种子 |
| MATLAB | `.m`/`.mlx`、函数与数据入口、图表导出 | MATLAB/Toolbox 版本、路径、随机数流 |
| Stata | `.do`、`.dta`/导入脚本、日志和表图导出 | Stata 版本、ado 包版本、完整 log |
| SAS | `.sas`、LIBNAME/格式定义、日志与输出 | SAS 版本、过程选项、日志警告与错误 |
| JASP/Jamovi | `.jasp`/`.omv`、数据字典、分析设置截图或可导出语法 | 软件版本、模块版本、分析选项与结果映射 |
| 其他 | 原生脚本/工程文件或平台中立分析契约 | 软件版本、依赖、随机性、执行与导出记录 |

## 统一分析契约

无论软件为何，都至少说明：

1. 分析单位和重复测量/聚类层级；
2. 输入文件、稳定 ID、变量类型、值标签和缺失编码；
3. 排除规则、派生变量公式和执行顺序；
4. 描述统计、主模型、对比、效应量、不确定性和敏感性分析；
5. 原文表图与输出对象的对应关系；
6. 随机种子、软件/包/模块版本、运行日志和导出文件；
7. 无法从论文确定的选项必须保留为显式占位符。

直接复制优先保留作者原分析环境；用户要求迁移时，同时保留“原分析契约”和“目标软件实现差异”。只有用户选择 R 时才读取 `r-reproducibility-guide.md`。
