# 问卷与纵向研究重建路径

横断问卷、重复测量、多波纵向、组织档案与问卷链接任务读取本文件。问卷平台是运行平台，但“题项显示成功”不等于测量、匹配和分析已经可复现。

## 横断问卷结构

按以下顺序重建：

1. 招募来源、资格筛选、知情同意、退出与重复参与规则；
2. Block/页面、题项稳定 ID、量表版本、许可、翻译、反向题和计分；
3. 题项/区组随机化、分支、跳题、必答、验证和注意检查；
4. 操纵或情境材料、测量顺序、共同方法偏差和需求特征；
5. 开始/结束、完成/部分完成、时长、设备、显示路径和质控 paradata；
6. 原始导出、值标签、缺失编码、排除、量表得分和分析字段。

## 纵向与多波结构

必须增加：

| 模块 | 需要明确的内容 |
|---|---|
| 波次计划 | wave ID、时间窗、目标间隔、允许偏差、每波构念/任务和版本变化 |
| 匿名匹配 | 不可逆 participant key、生成/发放/找回方案，与联系信息分离 |
| 联系与提醒 | 邀请、提醒次数与时间、退订、无效地址、拒绝和失访状态 |
| 路由 | 新进入、继续、补填、逾期、跳过、退出和不再联系分支 |
| 流失 | 每波邀请/打开/同意/完成/排除人数与原因，不把未响应自动当成随机缺失 |
| 测量稳定 | 题项、量尺、语言、平台和情境是否跨波一致；变化时记录版本差异 |
| 时间数据 | invitation/open/start/end 时间、时区、实际间隔、目标间隔偏差 |
| 分析接口 | 宽表/长表转换、time 变量、层级、缺失机制、FIML/MI/权重/敏感性计划 |

## 组织与多层链接

分别定义组织、团队、主管、员工和 dyad ID；说明谁生成链接键、谁能访问身份信息、怎样聚合、最小组规模、有效 N、跨层变量和离职/调岗处理。不要把组织名称、邮箱或工号直接放入公开分析数据。

## 平台产物

问卷实施至少输出：页面/Block 图、题项字典、显示与分支逻辑表、随机化、Embedded Data、wave plan、联系状态字典、导出字段表、质控/排除和测试矩阵。若用户未指定 Qualtrics、SoSci 或其他平台，先询问一次；未回答时给平台中立问卷蓝图，不默认 E-Prime。

## 语义校验

结构化计划中，横断问卷至少包含 `item_id`、`response_raw`、`completion_status`；纵向研究还必须包含 `participant_key`、`wave_id`、`invitation_status`，并定义至少两个波次。题项、逻辑、导出字段和分析变量必须使用稳定 ID 对齐。
